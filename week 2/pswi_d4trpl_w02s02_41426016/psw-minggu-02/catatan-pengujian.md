DevTools : 
1. Bahasa dokumen dengan HTML mempunyai lang=id,dimana lang=id menunjukkan bahasa utamanya yaitu bhasa Indonesia
2. Hierarki heading dengan h1, h2, dan h3 berurutan secara logis, h1 untuk judul utama, h2 untuk sub judul dan h3 untuk isi dari web tersebut
3. Landmark semantik lengkap yaitu header, nav, main, aside,footer ditemukan
4. Navigasi, dengan tautan menuju id yang tersedia
5. Judul halaman dengan title tampil pada  tab browser

Validasi : Saya menemukan error dimana tag <html> sudah ditutup terlebih dahulu sebelum tag <head> dibuka atau dapat dikatakan salah posisi. Perbaikan yang saya lakukan yaitu tag <head> berada di dalam tag <html>

Note : Saya menggunakan AI untuk melihat letak kesalahan kode, agar saya dapat mengerti dan tahu dimana kesalahan pada kode saya

Eksperimen : <footer id="kontak>  dimuat dalam sebuah kode yang akan terjdi yaitu tag tidak terbaca dan saat menu "kontak" diklik, halaman tidak akan bergulir ke bawah. Perbaikannya yaitu dengan menambahkan tanda petik dua pada kata kontak, <footer id="kontak">
